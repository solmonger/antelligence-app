## Proposed state limit

**1,400 characters** (v4.1: 1,200, set for Laya, which is dropped). Basis: S-talk natural length p95 + 300 notebook characters, rounded up to 100. 0.04% of the S-talk states are over it even before the notebook; p95 plus a full notebook is {'qwen3.5-4b': 419, 'qwen3.5-9b': 419, 'd1-3b': 397} tokens. Over the limit the renderer drops whole sentences, lowest priority first (notebook, colony note, readings, zones, marks, messages), never mid-sentence.

Changing `kernel/decision.py` `MAX_STATE_CHARS` (it also bounds `DecisionRequest.state`) is not done here: it needs a lead-signed note. `render_state(..., max_chars=N)` already takes the limit, and the default stays 1,200 so every v4.1 request hash is unchanged.
