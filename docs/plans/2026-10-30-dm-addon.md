# Decision models on top of the ants: preregistration

Date: 2026-10-30. Status: **frozen before any real call.** Code: `antelligence/experiments/dm_addon.py`,
`scripts/dm_addon.py`; fingerprint in `docs/research/dm-addon-20261030/prereg.json`; tests in
`tests/smarter_swarm/test_dm_addon.py`. Scope and background: `docs/plans/2026-10-30-decision-models-scope.md`.

## The question

Does a decision model (a model that only picks from a fixed list and gives a probability for each option) make the
swarm's answers better, on questions the swarm has already answered? It reads saved runs, so **it makes no new LLM
call**. Only the decision model is asked.

## The claim being tested

> On the fair test's 341 questions, adding Jev as a sixth voter to the five think-alone ants (`vote`) beats both the
> LLM asked five times (`single5`) and the five ants alone (`swarm5`), on exams and on forecasts.

## Sources (saved swarms)

| Source | What it holds | Role |
|---|---|---|
| `fair-test` | PR 21's live run: 240 exam questions and 101 forecasts, 5 ants (Step 3.7 Flash, each looking a different way), each ant's answer **and reason** from the reply cache | **primary** |
| `shared-read` | PR 23's run: 240 exam questions, 8 small local ants of 4 families answering alone (answers only, no reasons), plus the local reader alone | secondary, exams only |

`export` rebuilds each fair-test ant's request with the frozen fair-test code and finds its reason in the cache. If a
cached answer differs from the run's own row, it stops (the files are from different runs). If over 10% of reasons
are missing, it stops.

|---|---|---|---|

Perplexity's 26B Decider is not in the test: it needs CUDA and 52 GB.

## Arms

Every decision model gets the same four arms. Each one uses only the model's answers to two calls per question.

| Arm | What it is | LLM calls per question |
|---|---|---|
| `dm1` | the decision model alone, reading the question | 0 |
| `vote` | the ants' plain vote plus the model as one more voter. Exams: each ant is one vote, the model's probabilities are one vote spread over the options, a tie goes to the earlier letter. Forecasts: the mean of all clipped probabilities. | 5 (fair test) |
| `read` | the model reads the question and every ant's answer and the first 300 characters of its reason, then picks | 5 |
| `cheap` | the model alone when it is sure enough, else the ants' plain vote. The bar is the lowest of 0, 0.05 ... 1 that loses no more than the pass line against the ants on a fixed half of the questions (seed 20261030), and it is scored on the other half only | 0 to 5 |

LLM-only arms come from the saved runs as they are: `single1`, `single5`, `single10`, `swarm5`, `seen10` (fair test);
`reader`, `alone8`, `notes8`, `both8` (shared read).

Nothing here talks back to the ants, so nothing steers the swarm. `read` weighs the others' answers, which is the
closest thing to a checker. It is reported but is not the primary arm.

## Requests

- Exams: a `choice` question with the options as written, in a seeded order (a decision model can favour the first
  option). Forecasts: a `noul` (yes/no) question, "Will this question resolve YES?".
- The state is the question text (`dm1`) or the question plus "N people answered this on their own:" and one line
  per ant (`read`). Up to 24,000 characters; the longest built is about 6,000.
- Every forecast probability is clipped to 0.01 to 0.99, as the fair test clips its ants. A failed call counts as
  no vote (exams) or 0.5 (forecasts).
- Every reply is cached by request hash, so a stopped run resumes without paying twice. A failed call is asked again
  on a rerun. Five failures in a row stop the run.

## Measures and pass lines

- Exams: share right. Forecasts: Brier score (lower is better). Paired bootstrap 95% intervals, as the fair test.
- **Primary verdict** (fair test, Jev, `vote`): on each kind, `vote` beats both `single5` and `swarm5` by at least
  the pass line (exams +0.01, forecasts 0.005 lower Brier), each with its interval above zero.
  - **supported**: both kinds pass.
  - **mixed**: one passes.
  - **not supported**: neither passes.
  - **invalid**: under 90% of the decision model's or the ants' answers were usable.
- Also reported, not part of the verdict:
  - every arm for every model;
  - the exam split into logic (LSAT logical reasoning, LogiQA) and puzzles (LSAT analytical reasoning, AQuA-RAT);
  - the market crowd's own Brier score;
  - each model's calls, dollars and median seconds a call.

## Known limits

- The forecasts resolved after Step 3.7 Flash was released, but a decision model trained later may have seen some
  outcomes. If Jev scores far better on forecasts than on exams, that is the first suspect.
- AGIEval is public, so any model may have seen these exam questions. That cuts both ways and is the same for all
  arms on the same model.
- The shared-read source has no reasons, so its `read` arm sees answers only.
- `cheap` is scored on half the questions, so its interval is wider.
- One run per model. Decision models are close to deterministic, but servers can differ by version: the model each
  server reports is saved with every reply.
